# Описание проекта
Программа представляет собой асинправного Telegram-бота, разработанного на языке Python, который выполняет роль персонального фитнес-помощника. Бот позволяет пользователям получать готовые планы тренировок, вести интерактивный учет потребленных калорий с автоматическим расчетом макронутриентов, а также отслеживать прогресс активности и получать мотивационные цитаты. Для стабильной работы приложения в условиях сетевых ограничений в проект интегрирована поддержка прокси-соединения.


## Функциональные возможности
### Основной функционал
- Просмотр готовых программ тренировок (для дома и тренажерного зала)
- Выдача случайных спортивных мотивационных цитат
- Имитация настройки ежедневных напоминаний о тренировках
- Интерактивный счетчик выполненных за неделю тренировок

### Дополнительный функционал
- Пошаговый сценарий диалога (КБЖУ-калькулятор) с автоматическим скрытием клавиатуры
- Валидация вводимых данных пользователя (проверка на числовой ввод)
- Расчет пропорций макронутриентов (белки, жиры, углеводы в граммах) на основе введенных калорий


## Требования к системе
- **Python:** 3.10 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:**
  - `python-telegram-bot` (версия 20.x или выше) — для взаимодействия с Telegram API
  - `httpx` — для выполнения асинхронных сетевых запросов через прокси


## Установка и запуск
### 1. Клонирование репозитория
```bash
git clone https://github.com/radmilavlasova/fitness_tracker_bot.git
cd fitness_bot
```

### 2. Создание и активация виртуального окружения
**Windows:**
```bash
python -m venv venv
source venv/Scripts/activate
```
**macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка токена доступа
Перед запуском откройте файл `config.py` и вставьте ваш HTTP API токен, полученный от бота [@BotFather](https://t.me), внутрь кавычек:
```python
BOT_TOKEN = "ВАШ_ТОКЕН_ИЗ_ТЕЛЕГРАМА"
```

### 5. Запуск программы
```bash
python bot.py
```

### 6. Управление ботом в Telegram
- `/start` — Инициализация бота, вывод приветствия и запуск главного кнопочного меню.
- `Кнопка "Планы тренировок"` — Отображение списка упражнений.
- `Кнопка "Питание и КБЖУ"` — Переход в режим пошагового ввода калорий.
- `/cancel` — Прерывание текущего диалога ввода калорий и возврат в меню.

## Структура проекта
```text
fitness_bot/
├── .gitignore          # Исключение системного кэша и папки venv из индекса Git
├── README.md           # Документация проекта
├── requirements.txt    # Список внешних зависимостей и библиотек
├── config.py           # Конфигурационный файл (хранение токена API)
└── bot.py              # Главный модуль программы и логика хэндлеров
```

**Назначение основных модулей:**
- `config.py` — изолированное хранение секретных ключей авторизации бота.
- `bot.py` — точка входа в программу, инициализация приложения, асинхронные обработчики текстовых сообщений и сценария КБЖУ.
